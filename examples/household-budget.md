## 想定する来訪者の言葉

> 家計簿を作って

## 解析の例

## 来訪者向けの最初の説明

> 支出を入れると合計とグラフが変わる家計簿を作ります。まずはサンプルデータで見てみましょう。

## 画面イメージ

```text
┌────────────────────────────────┐
│ わたしの家計簿  [サンプルデータ]│
│                                │
│  今月の支出  ¥128,450           │
│                                │
│  食費    ██████████             │
│  住居    ████████               │
│  交通    █████                  │
│  その他  ███                    │
│                                │
│  支出を追加                     │
│  [金額     ] [カテゴリ ▽]      │
│               [＋追加する]      │
│                                │
│  最新の支出（架空データ）       │
│  ...                           │
└────────────────────────────────┘
```

金額と棒の長さはあくまで配置例。実装時はすべての表示を同一のデータから計算すること。

## 必須動作

1. 初期の架空明細の合計が `今月の支出` に一致する。
2. `食費` に `500円` を追加する。
3. 一覧に `500円` が1件増える。
4. 今月の合計が `500円` 増える（同じ月の日付の場合）。
5. 食費のグラフの値も `500円` 増える。
6. 金額が空／不正なら登録しない。
7. 保存しない設計なら `このセッション中のみ` とわかるようにする。

## 追加指示の例

> 円グラフにして。

**期待すること**：棒グラフを円／ドーナツに変えても、元データ・合計・追加動作はそのまま。割合が合計100%と整合する。

> 支出が多いカテゴリを赤くして。

**期待すること**：最大カテゴリを計算で特定して強調する。カテゴリ名だけで固定的に色を決めない。

## しないこと

- 銀行口座に接続した、CSVを読み込んだ、クラウドに保存した等と偽る。
- 表示上だけ増額し、内部データやグラフは更新しない。
- サンプルであることを隠す。
